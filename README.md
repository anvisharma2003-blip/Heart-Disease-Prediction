# Heart Disease Prediction using Machine Learning

## Project Overview
This project is based on Machine Learning techniques used to predict the possibility of heart disease using patient health data. The project includes data preprocessing, exploratory data analysis, model training, prediction, and performance evaluation.

## Technologies Used
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Features
- Data Cleaning and Preprocessing
- Exploratory Data Analysis (EDA)
- Model Training and Testing
- Logistic Regression Classification
- Accuracy Evaluation
- Data Visualization

## Machine Learning Concepts Used
- Supervised Learning
- Classification
- Train-Test Split
- Logistic Regression
- Model Evaluation Metrics

## Project Workflow
1. Import Dataset
2. Data Preprocessing
3. Feature Selection
4. Train-Test Split
5. Model Training
6. Prediction
7. Accuracy Evaluation
8. Visualization of Results

## Output
The model predicts whether a patient is likely to have heart disease based on medical attributes.
